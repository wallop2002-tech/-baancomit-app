# ระบบรวมงานร้าน (บ้านคอมไอที · นายไอที · ไนซ์ไอที)

แอปเดียวแทนชีต สมุดโอนครบ, จดยอดขายเซลล์ และ IT_STOCK_SYSTEM
รันบน Cloudflare Workers ฐานข้อมูล Cloudflare D1

โครงข้อมูลอยู่ใน `migrations/0001_init.sql` เงินทุกช่องเก็บเป็นสตางค์

## ตอนนี้ทำอะไรได้

- เลือกดูทีละกิจการ หรือกิจการแม่รวมกิจการย่อย (วีแคร์ยู, คุณหน่อย อยู่ใต้บ้านคอมไอที)
- สต็อกและรุ่นสินค้าเป็นของกิจการแม่ กิจการย่อยขายจากกองเดียวกัน
- เพิ่มรุ่นสินค้า (Product_ID)
- รับเครื่องเข้าตาม Serial ทีละหลายเครื่อง, นำออกแบบโอน/ใช้เอง
- บันทึกการขาย ผูกลูกค้า ทีม Serial เลขพัสดุ และยอด COD ในครั้งเดียว ขายแล้วตัดสต็อกอัตโนมัติ
- หน้าภาพรวม ยอดวันนี้ ยอดเดือน แยกกิจการ
- หน้าจับคู่ยอดเงิน: วาง statement ธนาคาร (ข้ามแถวซ้ำ) แล้วระบบเสนอออเดอร์ที่ยอดค้างตรงกัน กดยืนยันทีเดียว, วางไฟล์ COD แล้วจับคู่ด้วยเลขพัสดุอัตโนมัติ ออเดอร์ที่รับเงินครบเปลี่ยนเป็น paid
- หน้ารายงาน: ยอดขาย กำไรขั้นต้น (จากต้นทุนเครื่อง) แยกกิจการ ทีม รายวัน รุ่นขายดี ยอดค้างรับ COD รอโอน สต็อกคงเหลือ ดาวน์โหลดออเดอร์เป็น CSV เปิดใน Excel/Google Sheets ได้
- หน้าเคลม: ลูกค้าส่งเคลม/ส่งเคลมซัพพลายเออร์ (เช่น iPLAWAN) ติดตามรับคืน ส่งคืนลูกค้า เปลี่ยนเครื่องทดแทนได้ สถานะเครื่องเปลี่ยนให้อัตโนมัติ
- หน้าผ่อน: เปิดแผนจากออเดอร์ที่ขายแบบผ่อน รับงวด เห็นยอดคงเหลือ จ่ายครบปิดแผนและออเดอร์ให้เอง
- ผู้ใช้และสิทธิ์ตามบทบาทต่อกิจการ (ดูหัวข้อล็อกอิน)
- API ให้ระบบภายนอก (ดูหัวข้อ API)

## ติดตั้งครั้งแรก (ทำครั้งเดียว)

1. `npm install`
2. `npx wrangler login`
3. `npx wrangler d1 create baancomit-db` แล้วเอา `database_id` ที่ได้ไปใส่ใน `wrangler.toml`
4. `npm run db:migrate:remote`
5. `npm run deploy`

### ให้ deploy เองทุกครั้งที่ push เข้า main

ใน GitHub repo นี้ ไปที่ Settings → Secrets and variables → Actions แล้วตั้ง

- Secret `CLOUDFLARE_API_TOKEN` สร้างที่ Cloudflare dashboard → My Profile → API Tokens (template "Edit Cloudflare Workers" แล้วเพิ่มสิทธิ์ D1 Edit)
- Secret `CLOUDFLARE_ACCOUNT_ID`
- Variable `DEPLOY_ENABLED` = `true`

### ล็อกอิน

ใช้ Cloudflare Access (Zero Trust) ยืนยันอีเมล แล้วแอปตรวจสิทธิ์ตามบทบาทเอง

1. Cloudflare dashboard → Zero Trust → Access → Applications → Add (Self-hosted) ใส่โดเมนของแอป แต่ **ยกเว้น path `/api/*`** (ใส่ policy Bypass ให้ `/api` เพราะ API ใช้ token ของตัวเอง)
2. ตั้ง policy ให้เข้าได้เฉพาะอีเมลพนักงาน
3. จดค่า Team domain (เช่น `baancomit.cloudflareaccess.com`) และ Application Audience (AUD) tag แล้วตั้งเป็น secret
    ```
    npx wrangler secret put ACCESS_TEAM_DOMAIN
    npx wrangler secret put ACCESS_AUD
    ```
4. เปิดหน้า `/users` เพิ่มตัวเองเป็น "เจ้าของ" ของบ้านคอมไอทีเป็นคนแรก หลังจากนั้นระบบจะบังคับล็อกอินทุกหน้า (ก่อนมีผู้ใช้คนแรก แอปเปิดให้ทุกคนที่ผ่าน Access ใช้ได้)

บทบาท (ให้ที่กิจการแม่ครอบคลุมกิจการย่อย)

| บทบาท | ทำอะไรได้ |
|---|---|
| เจ้าของ | ทุกอย่าง รวมถึงจัดการผู้ใช้ |
| บัญชี | ดูทุกหน้า จับคู่ยอดเงิน รายงาน บันทึกออเดอร์และงวดผ่อน |
| เซลล์ | ดูหน้าทั่วไป บันทึกออเดอร์และงวดผ่อน |
| สต็อก/ช่าง | ดูหน้าทั่วไป รับ/นำออกเครื่อง เพิ่มรุ่น เคลม |

## API สำหรับระบบภายนอก

ตั้ง token: `npx wrangler secret put API_TOKEN` (สุ่มยาว ๆ) ทุกคำขอส่ง header `Authorization: Bearer <token>` เงินเป็นบาท

| คำขอ | ใช้ทำอะไร |
|---|---|
| `GET /api/serials/:serial` | สถานะเครื่อง |
| `GET /api/stock?business=WCY` | สต็อกพร้อมขายตามรุ่น (กิจการย่อยเห็นสต็อกกิจการแม่) |
| `GET /api/orders?business=BCI&from=2026-10-01&to=2026-10-31` | ออเดอร์ตามช่วงวันที่ |
| `POST /api/bank-transactions` `{business, account, txn_at, amount, description, ref_code}` | รับรายการเงินเข้าจากธนาคาร/ระบบอ่านสลิป ไปขึ้นหน้าจับคู่ยอดเงิน (ส่งซ้ำไม่ซ้ำ) |
| `POST /api/shipments/status` `{tracking_no, status, cod_amount?, fee?, settled_on?}` | อัปเดตพัสดุจากขนส่ง status = `delivered`, `returned` หรือ `cod_settled` (โอน COD แล้ว: บันทึกเงินและปิดออเดอร์ให้) |

รหัสกิจการ: BCI บ้านคอมไอที, NAI นายไอที, NICE ไนซ์ไอที, WCY วีแคร์ยู, NOI คุณหน่อย


## ย้ายข้อมูลปี 2026 จากชีตเดิม

1. ดาวน์โหลดแท็บเหล่านี้เป็น CSV (เปิดแท็บ > ไฟล์ > ดาวน์โหลด > CSV) ไว้ในโฟลเดอร์ `import-data/` ไม่ต้องเปลี่ยนชื่อไฟล์
    - IT_STOCK_SYSTEM: `MASTER_STOCK`, `STOCK_OUT`, `CLAIM_CUST`, `CLAIM_OUT`
    - สมุดโอนครบ: `วีแคร์ยู`, `KhunNoi`, `กสิกร`, `BankNoi`, `COD_WCY`, `COD_Noi`
    - จดยอดขายเซลล์: `เซลล์ทีม_1` ถึง `เซลล์ทีม_4`, `ร้าน`, `ADS`, `ผ่อน`
2. `npm run import -- import-data data.import.sql` (สรุปจำนวนแถวที่อ่านได้จะแสดงเป็นตาราง)
3. `npx wrangler d1 execute baancomit-db --remote --file data.import.sql`

รันซ้ำได้ แถวที่เคยนำเข้าแล้วจะไม่ซ้ำ ไฟล์ CSV และ SQL มีข้อมูลลูกค้าจริง ถูก ignore ไว้แล้ว ห้าม commit

สิ่งที่ทำ: นำเข้ารุ่นและเครื่องทุก Serial, ออเดอร์ปี 2026 ของวีแคร์ยูและคุณหน่อย พร้อมเลขพัสดุ ยอดโอน โอนเพิ่ม สด และ COD, ผูกเงินโอนกับแถว statement ด้วย Keyเช็คโอน, ค่าธรรมเนียม COD จากไฟล์ COD, และเคลม
แท็บเซลล์ทีม/ร้าน/ADS: สร้างออเดอร์ใหม่เฉพาะยอดที่ยังไม่มีในสมุดโอนครบ (เทียบด้วย KEY วันที่+ทีม+ชื่อ เช่น ขายรับหน้าร้าน) ทีม X คือหน้าร้าน นับเป็นคุณหน่อยตามสมุดโอนครบ ทีมอื่นเป็นวีแคร์ยู ปีของวันที่แบบ วว/ดด คิดจากลำดับแถว
แท็บผ่อน: นำเข้าแผนที่บันทึกปีนี้ หรือยังผ่อนไม่จบ ผูกกับออเดอร์ด้วย KEYSALE ถ้าไม่พบจะสร้างออเดอร์ผ่อนให้

## รันบนเครื่อง

```
npm run db:migrate:local
npm run dev
```

สร้างไฟล์ `.dev.vars` (ไม่ถูก commit) เพื่อทดสอบล็อกอินและ API บนเครื่อง

```
API_TOKEN=test-token
DEV_TRUST_EMAIL_HEADER=1
```

แล้วส่ง header `Cf-Access-Authenticated-User-Email: you@example.com` แทนการล็อกอินจริง ห้ามตั้ง `DEV_TRUST_EMAIL_HEADER` บนเซิร์ฟเวอร์จริง

## ยังไม่ได้ทำ
